# Krankenkassenbeitrag-Rechner

Kranken- und Pflegebeitrag 2026 für Angestellte, Selbstständige und Rentner.

## Eingaben

| Feld | Einheit | Vorgabe |
|---|---|---|
| Beitragspflichtiges Einkommen | €/Monat | 3.500 |
| Status |  | Angestellt (hälftig mit Arbeitgeber) |
| Zusatzbeitrag der Kasse | % | 2,9 |
| Krankengeldanspruch (Selbstständige) |  | Ja (allgemeiner Beitrag 14,6 %) |
| Kinder |  | 1 Kind |

## Berechnung

Bemessungsgrundlage = Einkommen, höchstens 5.812,50 € (Selbstständige mindestens 1.318,33 €)
KV-Beitrag = Bemessungsgrundlage × (14,6 % bzw. 14,0 % + Zusatzbeitrag)
PV-Beitrag = Bemessungsgrundlage × (3,6 % + 0,6 % Kinderlosenzuschlag − 0,25 % je Kind ab dem 2. bis zum 5.)
Angestellte tragen die Hälfte des KV-Beitrags (§ 249 SGB V). In der Pflegeversicherung zahlt der Arbeitgeber 1,8 %, den Rest einschließlich Kinderlosenzuschlag trägt der Beschäftigte (§ 58 SGB XI). Rentner zahlen die Hälfte des KV-Beitrags, den Pflegebeitrag allein. Selbstständige zahlen beides vollständig; ohne Krankengeldanspruch gilt der ermäßigte Satz von 14,0 % (§ 243 SGB V).
Die Mindestbemessung von 1.318,33 € folgt aus § 240 Abs. 4 SGB V: pro Kalendertag der neunzigste Teil der monatlichen Bezugsgröße von 3.955 € (Rechengrößenverordnung 2026), auf 30 Tage hochgerechnet.

## Beispiel mit den Vorgabewerten

**Ihr Beitrag (ca.):** 369,25 €
- Krankenversicherung gesamt: 612,5
- Pflegeversicherung gesamt: 126
- Bemessungsgrundlage: 3.500

## Grenzen

Werte 2026 (BBG 69.750 €/Jahr, gesetzlicher durchschnittlicher Zusatzbeitrag 2,9 %). Sachsen hat eine abweichende Aufteilung der Pflegeversicherung; weitere Einkommensarten können bei freiwilliger Versicherung zählen.
