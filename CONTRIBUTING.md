# Fehler melden und mitwirken

Danke, dass Sie helfen, die Rechner genauer zu machen.

## Rechenfehler melden

Legen Sie ein Issue an und nennen Sie:

1. den Rechner (Link zur Seite auf rechnercenter.de),
2. Ihre Eingaben,
3. das Ergebnis des Rechners und das Ergebnis, das Sie erwartet hätten,
4. wenn möglich eine Quelle: Gesetz, amtlicher Rechner oder Veröffentlichung einer Behörde.

Alternativ per E-Mail an rechnercenter@gmail.com.

## Was angenommen wird

- Korrekturen mit Beleg aus Gesetz, amtlichem Programm oder Behördenveröffentlichung.
- Hinweise auf veraltete Werte mit Quelle des neuen Werts.
- Klarere Erklärungen einzelner Rechenschritte.

Ergebnisse anderer Online-Rechner gelten nicht als Beleg – sie können selbst falsch sein.
