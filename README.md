# Rechnercenter – Methodik

So rechnen die Rechner auf [rechnercenter.de](https://rechnercenter.de): Formeln, Annahmen, Grenzen und Quellen – offen und nachprüfbar.

Dieses Repository enthält **keinen Programmcode der Website**, sondern die Rechenregeln. Jede Datei unter `rechner/` beschreibt einen Rechner: Eingaben, Berechnung, ein Beispiel mit den Vorgabewerten, Grenzen und die amtlichen Quellen.

## Warum offen?

Online-Rechner liefern oft eine Zahl, ohne zu zeigen, wie sie entsteht. Hier kann jede und jeder nachvollziehen, wie gerechnet wird, und Fehler melden.

## Wer dahintersteht

Rechnercenter ist ein Nebenprojekt von **Aayush Thakur**, Webentwickler und SEO-Spezialist. Ich bin weder Steuerberater noch Anwalt oder Arzt und stütze die Berechnungen deshalb auf Gesetzestexte, amtliche Programme und Tabellen. Mehr: [Über uns](https://rechnercenter.de/ueber-uns).
